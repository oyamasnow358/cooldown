# こころの火山 クールダウン（MieeL）

いかり・いらいらを じぶんで しずめる れんしゅうを する、アンガーマネジメントの アプリです（特別支援教育向け・iPad の全画面アプリとして使えます）。

## ながれ
1. **いま どんな きもち？** … こころの火山と「きもちの おんどけい」（0 おだやか 〜 4 ばくはつ）で つたえる
2. **クールダウン** … きもちの つよさに あわせて どうぐを すすめる（つよい ときは からだ → さがってきたら ことば）
3. **いまの きもちは？** … どうぐの あとに ふりかえり、火山が ひえていく
4. **これから どうする？** … もどる・せんせいと はなす・みずを のむ など を えらんで おわり

## どうぐ（9しゅるい）
- 🐡 いきを とめて かぞえよう … インカメラで じぶんを うつし、すって → とめて（3〜10びょう）→ ふーっ
- 🪞 かがみで しんこきゅう … インカメラの まわりの わが ふくらむ・しぼむ のに あわせて いきを する
- 🕯️ ろうそく ふーっ … マイクで いきを きき、ながい いきで ろうそくを けす（マイクが ないときは ボタン）
- ✊ ぎゅっと ふわっ … て・かた・かお・あしに ちからを いれて ぬく
- 🫧 しずかに やすむ … すいそうを ながめる タイマー（なみの おと）
- 🔢 かぞえて おちつく … 10→1 など じゅんばんに タッチ
- 👀 さがして おちつく … まわりの「あかい もの」などを さがす
- 💬 きもちを ことばに … なにが あった → からだ → きもち を えらんで、できた ぶんを こえに だして よむ
- 📖 よんで おちつく … じぶんに かける ことばを カラオケの ように よむ（先生が かえられる）

## 先生用（⚙️ を 1.5秒 ながおし）
- 子どもごとの プラン（おまかせ／きめた じゅんばん／子どもが えらぶ）、どうぐの オン・オフと こまかい せってい
- きろく：まえ → あと、なにが あった・きもち、じかんたい、**その子に よく きいた どうぐ**（おまかせ プランにも はんえい）、CSV 保存
- プリント（A4）：きもちの おんどけい／クールダウン プラン／よんで おちつく カード／ふりかえり シート／きろく
- 「やすみの しゅくだい メーカー」から プリントを とりこめます（MieelPrintAPI）

カメラ・マイクは その場で 画面に うつす・音の 大きさを はかる だけで、ほぞん・送信は しません。データは この端末の中だけに 保存されます。
